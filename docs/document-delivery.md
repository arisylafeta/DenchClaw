# Agent document delivery (local implementation)

Any local agent that can run Node can use this source helper. No Hermes runtime or profile installation is performed.

```sh
node --experimental-strip-types scripts/document-delivery.mjs --help
node --experimental-strip-types scripts/document-delivery.mjs \
  --workspace /absolute/operator-selected/workspace --file reports/summary.md
node --experimental-strip-types --test scripts/document-delivery.test.mjs
```

Requires Node >=22.12 with native type stripping (the CLI reuses the app's link/path helpers). Run from this repository. JSON stdout has schemaVersion 1, exact real file path and workspace root, relative path, MIME/editor capabilities, SHA-256 byte revision, root-relative openPath, full CRM openUrl and authenticated retrievalUrl. Errors go to stderr with nonzero exit. Supported: MD, TXT, DOCX, CSV, XLSX, JSON, JS, TS, PY, CSS. Type capability is based on extension, not a promise that malformed file bytes can be parsed. Legacy DOC/PPTX are deliberately unsupported.

Return a normal Markdown link to `openUrl` in the agent's final chat message, e.g. `[Open summary](https://crm.rebattery.io/?path=...)`. The existing chat/workspace link seam opens exact file identity through state, including new files absent from the tree. `openPath` is preferred inside this app. No second navigation/registry system or structured tool card is added. Agents must actually include this link; this does not automatically install a tool into every external Hermes process.

## Trust and limits

`--workspace` is an explicit trusted operator boundary, never a chat-supplied access grant. The helper checks directory/file realpaths, symlink escape, regular file and supported extension, and reads existing local bytes. It does not upload, authorize roots, change API access policy or trust client envelope fields. Existing server routes still enforce their own access rules; a helper success cannot guarantee the server can access an operator-selected workspace. Use an already authorized workspace. Do not use this as a sandbox against concurrent hostile filesystem mutation. Full URLs default to https://crm.rebattery.io; use `--origin` for an authorized local app. Foreign-origin links are not treated as app documents.

Revision describes generated bytes only. It is not save compare-and-swap or conflict protection. A dirty editor's explicit save can overwrite external changes under existing save semantics.
